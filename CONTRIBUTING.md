# Contributing

Contributions to BMC Helix Client are welcome!

Whether you want to report a bug, suggest an improvement, improve documentation, or submit code, your contribution is appreciated.

## Reporting Bugs

If you find a bug:

1. Check whether the issue has already been reported.
2. Open a new GitHub issue.
3. Describe the problem and how to reproduce it.
4. Include relevant error messages or examples, without exposing credentials or sensitive information.

## Suggesting Improvements

If you have an idea for a new feature or improvement:

1. Open a GitHub issue.
2. Explain the proposed change.
3. Describe the problem it solves or the benefit it provides.

For significant changes, please discuss the proposal before submitting code.

## Submitting Changes

1. Fork the repository.
2. Create a branch for your changes.
3. Implement your changes.
4. Test your code.
5. Commit your changes with a clear message.
6. Open a Pull Request describing what was changed and why.

## Code Guidelines

Please keep contributions:

- Simple and easy to understand.
- Consistent with the existing code structure.
- Focused on the proposed change.
- Independent of environment-specific configurations.

Avoid including credentials, tokens, private URLs, or sensitive information in code, examples, and issue reports.
